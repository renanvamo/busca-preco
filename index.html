Conectar o botão ao GitHub (uma vez, neste navegador)

Para iniciar a busca, a página precisa de um token do GitHub que só pode rodar workflows deste repositório:

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” → busca-preco.
  3. Repository permissions → Actions: “Read and write”. Nenhuma outra permissão.
  4. Cole o token abaixo. Ele fica salvo só neste navegador e nunca vai para o repositório.
